Troubleshooting

Find the failing step.

A reachable computer does not necessarily mean your credentials or AI model are working.

Connection and authorization

HTTP 401 — rejected credentials

Run the installer again, generate fresh pairing details and scan the new QR or enter its six-digit code. The installer-managed username is opencode. Manual servers may use a different username; use advanced options.

For a saved connection, a blank password field means keep the existing password. Older versions may fail a test with this field blank. The development update fixes this test behavior.

Computer not found / timeout

Check power, network and Tailscale state. Use the computer address printed next to the code. Do not expose the server on a public interface to fix a connection error.

Pairing code expired or used

Codes work once for ten minutes. Run the installer again for a fresh code; never share the QR or pairing link.

Connected, but the model does not answer

OpenCode server authorization and provider or CLI agent authorization are separate. Check the agent on the computer. A session error or repeated attempts can indicate a provider/network/model problem.

Run the installer diagnostic

Use the commands below on your computer. Do not post secrets or full pairing links in reports.

& ([scriptblock]::Create((irm https://raw.githubusercontent.com/jainikdroid-bit/AgentLink/main/tools/opencode-connect.ps1))) -Doctor
curl -fsSL https://raw.githubusercontent.com/jainikdroid-bit/AgentLink/main/tools/opencode-connect.sh | sh -s -- --doctor
