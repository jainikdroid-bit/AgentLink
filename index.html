Questions

Do I need an AgentLink account?

No. LAN needs no network account; remote Tailscale access requires a Tailscale account. Your AI provider or CLI agent may require its own sign-in.

Can I connect to a VPS?

Yes, if you run the agent on a VPS you control and make it reachable through a private network such as Tailscale.

What if I get HTTP 401?

The server rejected credentials. Generate fresh pairing details, then pair again. See the troubleshooting guide.

Is it free?

The client is MIT-licensed. Hosting and AI provider usage may have separate costs.
