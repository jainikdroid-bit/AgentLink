Install in three actions

  1. Open the release's Assets and select an APK compatible with your Android device.
  2. Check the published checksum if provided. Allow installation from your browser only if needed.
  3. Open AgentLink and follow the connection guide.
APK architecture or signing issue?

ARM64 suits most modern Android phones. Android requires compatible signing keys for updates. Back up any important configuration before uninstalling a differently signed build.
