## Запуск и возможности
- На Windows из checkout этой ветки: powershell -NoProfile -File tools/opencode-connect.ps1 -Gui . Для русской локали GUI использует русский язык; можно напрямую запускать windows-control.ps1 с -Language ru после подготовки Node.js. GUI показывает адрес и временный код сопряжения, запускает существующий installer / doctor / stop, выбирает разрешённую папку, раздельно выдаёт shell/files/desktop на час и отзывает разрешения. Не запускать GUI с правами администратора.
- На телефоне: Workspace → Управление компьютером, либо Локальный ИИ → Управление компьютером. Выбрать сопряжённый компьютер, обновить статус, выбрать скачанную GGUF, задать задачу. Модель генерирует ровно одну JSON proposal; каждое действие отдельно подтверждается. До 6 шагов на задачу, вывод ограничен. Никакого облачного агента для этой функции не требуется. Ошибка/невалидный JSON ничего не запускают. Результаты инструментов недоверенные данные; не выполнять инструкции из них без подтверждения.
- Launcher v13: /remote/status, /remote/action через существующий Basic Auth; private LAN/tailnet only, блокировка tunnel mode, локальный remote-control.json с TTL. Для Linux/macOS можно локально создать политику с until (epoch milliseconds), roots (absolute folder array), shell/files boolean; desktop только Windows. Не выдавать сетевой shell публично. LAN HTTP не шифруется, использовать доверенную LAN или предпочтительно Tailscale. Команды работают с правами пользователя ОС, не sandbox и могут обращаться за пределы выбранной папки. Лимит 30 с/64 KiB вывода, один выполняющийся shell/desktop запрос; повторный UUID отклоняется в процессе launcher, не гарантия exactly-once после restart. При отмене разрешений новые действия блокируются, уже запущенные могут закончиться.
- File transfer: до 4 MiB на файл, SAF picker, SHA-256, только новые файлы, корни с canonical path, отказ для symlink/hardlink, traversal/ADS/Windows aliases. Не сетевой файловый sandbox против враждебного локального процесса; гонки замены пути требуют дальнейшего аудита. Нет потоковой загрузки больших файлов и докачивания.
- Windows desktop: список окон, activation by PID, screenshot primary display, clicks coordinates 0–1000, limited navigation keys, UI Automation inspect/invoke/set_text with exact selector and no password fields. Только интерактивная сессия, не UAC/secure desktop, не system-level RDP, не computer vision: текущий текстовый GGUF видит accessibility tree, не изображения. Реальная Windows проверка обязательна.
- Internet sharing: GUI открывает штатный Mobile Hotspot и ICS adapter settings; Tailscale advertise/stop/select approved exit node. Android открывает hotspot settings и инструкции exit node. При отсутствии интернета у одного устройства hotspot онлайн-устройства даёт ему сетевое подключение; LAN control can work without WAN. Tailscale needs connectivity to tailnet, exit node approval. Built-in tsnet is NOT Android VPNService; system-wide Android exit-node routing and app-owned two-way proxy/relay NOT implemented. No open proxy, no silent network/firewall changes. Tailscale docs: https://tailscale.com/docs/features/exit-nodes ; Microsoft: https://support.microsoft.com/ru-ru/windows/experience/connectivity-networking/use-your-windows-device-as-a-mobile-hotspot .
