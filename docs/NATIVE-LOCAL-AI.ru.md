# Локальный ИИ без Termux — решение владельца

**Одно Android-приложение, без внешнего терминала.** Запрос владельца отменяет прежний вариант обязательного Termux. Старый телефонный MCP-инструмент Termux оставлен для совместимости и не участвует в локальных моделях. Не предлагать его новичку как обязательное действие.

## Реализация в ветке
- CMake и JNI: android/app/src/main/cpp/CMakeLists.txt и local-model.cpp. Встроенный llama.cpp из upstream commit 9777256c3130fa3201327bfab44bae187f7caea2 (b9354), CPU для arm64-v8a/x86_64; 32-битная сборка сообщает отсутствие движка. Зависимость скачивается при сборке, не на устройстве. Не меняет Cheri, React Native New Architecture или Tailscale.
- LocalModelModule.kt: private filesDir, HTTP range resume, строго HTTPS/HF redirects, неизменяемая revision и обязательный SHA-256, проверка magic GGUF, отмена, прогресс, удаление, проверка RAM/thermal, single-flight. JNI генерирует до 256 токенов, освобождает модель и контекст; реальные timings из llama_perf_context. Поддерживаются только decoder-only модели с шаблоном, который понимает llama_chat_apply_template. Пока CPU, один запрос, без GPU/NPU, streaming и многоходовой памяти.
- app/phone-models.tsx и src/lib/native-local-models.ts: каталог публичных single-file GGUF, локальная библиотека AsyncStorage, скачивание, подбор по грубой оценке RAM/диска, контекст, потоки, генерация/скорость/отмена. Вход с экрана подключений даже без ПК. Не обещать гарантированную совместимость. Рекомендации пока ориентировочные; учитывать KV cache и точную архитектуру при доводке. Не запрашивать доступ к gated/private моделям.
- Termux CLI-реализация нового раздела удалена, не возвращать её в основной flow.

## Остальные задачи текущего прохода
- app/workspace.tsx: несколько ПК/VPS, опрос метрик и агентов, Git status/history/diff/stage/unstage/commit/branch/switch, создание worktree, сохранение UTF-8 с revision, подсветка в отдельном предпросмотре, открытие частного dev-server в браузере, черновик передачи агенту, resume ID при наличии capability, журнал событий и benchmark.
- tools/git-workspace.js: opt-in AGENTLINK_GIT_ROOTS, AGENTLINK_GIT_WRITE=1 для записи, фиксированные команды, границы canonical path, symlink отказ для редактирования, проверка ревизии. Работать только с доверенными репозиториями владельца. Нет push/pull/PR и безопасного удаления worktree пока. Согласованность с активными агентами, гонки между внешними процессами, Git config и Windows junction требуют проверки; optimistic hash не является межпроцессной блокировкой.
- ACP session/load поддержка при заявленной capability; ручной ID, пока без автоматического session/list. Handoff из последних видимых сообщений, предварительный просмотр/редактирование; не отправляется автоматически. Убедиться, что черновик не содержит секретов. Нет автоматического оркестратора.
- Мониторинг: CPU/RAM/диск и NVIDIA GPU/VRAM/temperature через nvidia-smi, отсутствующие сенсоры неизвестны; benchmark Ollama/llama.cpp по официальным timing counters. Квота подписки неизвестна без предоставления провайдером; ACP usage отдельно. Не имитировать универсальный процент лимита.
- ACP inbox: сохраняет только metadata событий на ПК, optional FCM v1 (локальный service account + регистрационный токен телефона). Нужны реальные Google Services/Firebase credentials и тест на Android. Не считать доставку гарантированной при force stop. Старые notification actions привязаны к connectionId и pending permission; проверить гонки, безопасность при смене сервера и endpoint.
- Launcher v9. Уточнить updater и реальный запуск. Добавлены тесты phone-models, workspace-pure, workspace-integration, model-benchmark, protocol session/load. В изоляте: 6 проверок metadata/локализации/отсутствия Termux прошли; mock Ollama вернул 30 decode и 20 prefill t/s и отказ для неизвестной модели; синтаксис четырёх серверных JS-файлов проверен. Это не полный Node/Android прогон.
- Новые строки EN/RU, остальные языки используют английский fallback до перевода.
