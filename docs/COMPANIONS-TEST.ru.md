# Тестирование 3D-маскотов AgentLink

## Что изменено и почему

Byte и Orbit — самостоятельные процедурные полнотелые модели Three.js. Cheri, её VRM, сцена, клипы и жесты не менялись. Сценарии относятся только к новым моделям, но нативную регрессию Cheri нужно проверить после сборки.

Первый прогон реальной логики scene.ts с подставным Three.js renderer показал две проблемы у обеих моделей: working и writing имели одинаковые позы/предметы (отличался цвет); ходьба могла продолжаться после перехода offline. Исправлено: отдельная клавиатура Byte и шестерня Orbit при работе, планшет при написании, наклон головы/лапа у Byte при размышлении и сканирование у Orbit; отдельный индикатор ошибки; прекращение ходьбы при любом не-idle состоянии; плавные переходы, защищённые параметры walk, явная остановка игровой реакции при смене настроения, адаптация камеры к узкому окну.

## Воспроизводимый прогон логики

```sh
node --test tools/companions3d.test.js
```

Тест выполняет исходный web/companions3d/scene.ts с детерминированными часами и подставными объектами Three.js. Реальный GPU/WebGL не используется. По пять тестов на Byte и Orbit: 8 настроений, предметы/цвета, ходьба в обе стороны и прерывание, разные позы, некорректные входы/1200 быстрых кадров, узкий viewport.

Результат в ChatGPT: **10/10** — выполнены тела тех же тестов в JS-изоляте, с удалением TS-аннотаций непосредственно из полученного GitHub scene.ts, вместо Node stripTypeScriptTypes и node:test. SHA исходника 974c69bbcfbdd7e732b803455be28b7d26631c74; SHA теста 703c5f2a330f7239c502b57363324c403bcb48bd. Команда Node выше в полном checkout ещё не выполнена. Это не проверка внешнего вида или Android.

## Лаборатория реального рендеринга

```sh
npm ci
node scripts/build-companions3d.mjs --lab
```

Откройте .companion-lab/byte.html и .companion-lab/orbit.html в Chromium с WebGL. Лаборатория содержит ручной выбор 8 состояний, walk/stop/pet, четыре сценария с автоматическим воспроизведением и четыре ширины окна (50, 84, 112, 200 px). В штатную APK отладочная панель не входит. При необходимости используйте локальный HTTP-сервер в этой папке. Проверяйте консоль и сохраните скриншоты/видео реального рендера. Lab HTML создан, но реальная сборка и визуальная проверка не выполнены в ChatGPT: нет установленной зависимости Three.js и DNS для загрузки зависимостей.

## Сценарии характера

| Состояние | Byte | Orbit | Ожидание |
|---|---|---|---|
| idle | мягкое покачивание, движение хвоста, моргание | плавное покачивание, моргание | ненавязчивое ожидание |
| thinking | склоняет голову, поднимает лапу | поворачивает голову, сканирует пространство | понятно, что агент думает |
| working | работает за мини-клавиатурой | вращает шестерню | явно отличается от writing |
| writing | держит планшет с линиями | держит планшет | ответ формируется |
| loading | кольцо ожидания | кольцо ожидания | не показывать успех |
| success | подпрыгивает, поднимает лапы | поднимает руки, светится | короткая радость |
| error | поникшая голова, красный восклицательный знак | тревожный сигнал, опущенная голова | ошибка не маскируется игрой |
| offline | закрывает глаза, перестаёт ходить | переходит в спящий режим | не мешает интерфейсу |

### Автоматические последовательности в lab
- Normal job: loading → idle → thinking → working → writing → success → idle.
- Failure and recovery: thinking → working → error → offline → loading → thinking → success → idle.
- Walk interrupted: idle → walk right → working → writing → success → idle → walk left → offline → loading → idle.
- Stress: 32 переключения каждые 120 мс, затем idle.

### Android: обязательная приёмка (не пройдена в чате)
1. Запуск и выбор каждого персонажа, выключение/включение, смена при ходьбе и в активной сессии, восстановление после перезапуска.
2. Drag/hold/pinch при ширине 50–200 dp, положение у каждого края, изменение ориентации, клавиатура. Обычный тап должен пройти к интерфейсу.
3. Ошибка модели, отмена и потеря связи не должны давать ложное празднование; проверить существующий общий хост и источник activity. Не изменять поведение Cheri без согласования; если обнаружена общая проблема, описать её отдельно.
4. Проверить паузу при сворачивании, отсутствие утечек WebView/таймеров, плавность на реальном устройстве, нагрузку CPU/GPU. Проверить прозрачность 50/75/100%, контраст на четырёх темах, отсутствие обрезания ушей/хвоста/рук и читаемость поз при маленьком размере.
5. Сделать скриншоты и сравнить с Cheri по качеству анимации. Процедурные модели не выдавать за VRM. Если качество недостаточное, довести новые модели, не менять оригинальную Cheri.

Не публиковать APK или объединять ветку без разрешения владельца.
