## Реализовано в текущем проходе
1. Launcher v11: /acp/agents возвращает busy, число pendingPermissions, lastActivity, protocol session ID. Workspace global attention сортирует approval > busy > idle > unknown; отдельный connectionId, скрывает offline/ended, открывает точный чат. 
2. /acp/:id/queue GET/POST: до 20 pending prompts на процесс; enqueue/remove/pause/resume; UUID idempotency, отдельный RPC namespace. Работает при закрытом телефоне, пока запущен процесс агента. После non-end_turn, ошибки или cancel очередь останавливается до ручного Resume. Не перезапускает незавершённую задачу; очередь в RAM и не восстанавливается при перезапуске launcher. Не сохранять prompts на диск без отдельной политики шифрования. Пока нет reorder, edit или offline enqueue.
3. Git ls-files -z tracked/неигнорируемые untracked: 4000 записей максимум, поиск до 80 совпадений на экране, разрешённый root, доступ read-only. Созданный worktree автоматически выбран для нового запуска агента. Симлинки/бинарные/небезопасные файлы по-прежнему отклоняются при открытии. 
4. LiveCodeEditor: собственный локальный textarea/pre overlay, выделение синтаксиса по лексическим категориям, CSP no network, источник через JSON с экранированием, без innerHTML, только валидированные change events. CRLF восстанавливается, >64 KiB/смешанные EOL — native fallback. Сохранение остаётся revision-checked. Это не полноценный CodeMirror или language server; мобильные клавиатуры/scroll/undo и визуальный контраст необходимо проверить.
5. Встроенный предпросмотр частного dev-server: WebView без bridge и auth, JavaScript выключен по умолчанию, явное включение только для доверенного сайта, same-origin top-level navigation, external browser fallback, reload. Не является сетевым sandbox: JS/подресурсы могут отправлять сетевые запросы, не открывать недоверенный сайт. HMR и Tailscale loopback forwarding требуют Android-теста. 
6. Локальный ИИ: Eco/Balance/Quality профили с ограничением по CPU/доступной RAM, фиксированный benchmark prompt + до 128 output tokens, отдельные prefill/decode скорости и wall time, история 50 результатов на телефоне, очистка. Никакой скрытой телеметрии. Сравнение корректно только с одинаковым контекстом/threads/engine; не является обещанием качества. 
7. EN/RU строки, другие языки используют English fallback до перевода. Cheri не меняли.
