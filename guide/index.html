Setup guide

Connect your phone.

One installer command, then QR or a six-digit code. Pick the connection that matches your situation.

Same Wi-FiRemote accessНа русском

LAN · 2 steps

Use only on a trusted local network; no Tailscale account needed. Do not forward the OpenCode port to the public internet.

1. Prepare the computer

Open PowerShell or Terminal, paste the command and press Enter.

Windows · PowerShell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/jainikdroid-bit/AgentLink/main/tools/opencode-connect.ps1))) -Mode lan
Linux / macOS · Terminal
curl -fsSL https://raw.githubusercontent.com/jainikdroid-bit/AgentLink/main/tools/opencode-connect.sh | sh -s -- --mode lan

2. Install and pair

Download AgentLink for Android, open the app, scan the pairing QR (not the APK QR), or enter the six-digit code. Confirm your computer.

Why does it need a password?

The installer generates a random server password. QR or code pairing transfers it to the phone. LAN HTTP is not encrypted on its own; use a trusted network.

Tailscale · 3 steps

1. Run the installer

Open PowerShell or Terminal and run the command. Sign in to Tailscale on the computer when prompted.

Windows · PowerShell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/jainikdroid-bit/AgentLink/main/tools/opencode-connect.ps1)))
Linux / macOS · Terminal
curl -fsSL https://raw.githubusercontent.com/jainikdroid-bit/AgentLink/main/tools/opencode-connect.sh | sh

2. Prepare the phone

Install the AgentLink APK and Tailscale. Sign into the same Tailscale account as the computer.

3. Pair

Scan the connection QR, enter the code or paste the private pairing link. Confirm the computer and connect.

Can't find the computer?

Check that the computer is awake and both devices are on the same tailnet. Type the address printed beside the code if automatic discovery fails. Codes are valid once for ten minutes.

LAN · 2 шага

Шаг 1. На компьютере откройте PowerShell или Терминал и выполните команду.

Windows · PowerShell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/jainikdroid-bit/AgentLink/main/tools/opencode-connect.ps1))) -Mode lan
Linux / macOS · Terminal
curl -fsSL https://raw.githubusercontent.com/jainikdroid-bit/AgentLink/main/tools/opencode-connect.sh | sh -s -- --mode lan

Шаг 2. Откройте приложение, отсканируйте QR подключения или введите 6 цифр с компьютера. Подтвердите имя компьютера.

Зачем нужен пароль?

Пароль создаётся установщиком автоматически. QR или одноразовый код передаёт его приложению. Используйте LAN только в доверенной домашней сети, не открывайте порт в интернете.

Tailscale · 3 шага

Шаг 1. Запустите команду на компьютере и войдите в Tailscale при запросе.

Windows · PowerShell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/jainikdroid-bit/AgentLink/main/tools/opencode-connect.ps1)))
Linux / macOS · Terminal
curl -fsSL https://raw.githubusercontent.com/jainikdroid-bit/AgentLink/main/tools/opencode-connect.sh | sh

Шаг 2. Установите Tailscale на телефон, войдите в тот же аккаунт.

Шаг 3. Сканируйте QR подключения, введите код или вставьте ссылку сопряжения. Нажмите «Подключиться».

Ошибка 401 или не найден компьютер

401 — сервер отклонил пароль или логин. Повторно запустите установщик и получите новую ссылку. Имя пользователя установщика — opencode. При проблемах сети проверьте, что компьютер включён, а устройства используют один tailnet или домашнюю сеть.

Подключение есть, но модель не отвечает

Вход AgentLink не заменяет авторизацию OpenCode, Codex или Claude Code. Настройте выбранного агента на компьютере. Не передавайте пароли, QR и токены третьим лицам.
