# AgentLink — авторизация и подключение

## Что исправлено
- `tools/launcher.js`: POST /pair теперь проверяет наличие сохранённого пароля до погашения одноразового кода. Если пароля нет, возвращается HTTP 503 без выдачи учётных данных; код остаётся действительным до истечения срока.
- Версия launcher повышена с 6 до 7, чтобы установщик перезапустил старый launcher при обновлении.
- `tools/launcher.test.js`: добавлен регрессионный тест отсутствующего пароля, последующего восстановления и одноразового использования кода.

## Почему
Ранее правильный код мог привести к ответу ok:true с пустым паролем, одновременно погасив код. Телефон затем не мог авторизоваться. Исправление не отключает проверку пароля, лимиты попыток или срок действия кода.

## Простой гайд (Windows + Android)
1. На компьютере установите/обновите AgentLink по [официальной инструкции проекта](docs/INSTALL.ru.md). Пока исправление находится в отдельной ветке, установщик из main его не включает.
2. На компьютере и телефоне включите Tailscale с одной учётной записью. Не используйте публичный туннель для чувствительных задач.
3. На компьютере запустите установщик. В приложении выберите сканирование QR для подключения и подтвердите. Если камера недоступна, используйте код из установщика (однократно, 10 минут).
4. Если не соединяется, запустите установщик с -Doctor (Linux: --doctor). Проверьте serverHealthy, tailscaleState и passwordSaved. Не публикуйте полный вывод, если в нём есть пароль или ссылка сопряжения.
5. При смене пароля используйте -Stop, затем повторный запуск с -Rotate и новое сопряжение телефона. Не удаляйте пароль вручную. Старые подключения потребуют новых данных.
6. Для Codex или Claude Code откройте «Сеансы → Другие агенты». Вход в соответствующего агента выполняется отдельно на компьютере; вход AgentLink не заменяет авторизацию провайдера.

### Команды проверки (PowerShell)
```powershell
$u = 'https://raw.githubusercontent.com/jainikdroid-bit/AgentLink/main/tools/opencode-connect.ps1'
& ([scriptblock]::Create((irm $u))) -Doctor
```
Для Linux/macOS:
```sh
curl -fsSL https://raw.githubusercontent.com/jainikdroid-bit/AgentLink/main/tools/opencode-connect.sh | sh -s -- --doctor
```

## Границы
Это исправление сопряжения AgentLink, а не обход региональных ограничений, OAuth, проверки телефона или входа в OpenAI. Не менялись настройки провайдеров, Tailscale или Android Keystore. Не публикуйте pairingLink, пароль, токены и логи с секретами.
