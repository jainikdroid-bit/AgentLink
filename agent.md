# AgentLink — авторизация и подключение

## Что исправлено
- `tools/launcher.js`: POST /pair теперь проверяет наличие сохранённого пароля до погашения одноразового кода. Если пароля нет, возвращается HTTP 503 без выдачи учётных данных; код остаётся действительным до истечения срока.
- Версия launcher повышена с 6 до 7, чтобы установщик перезапустил старый launcher при обновлении.
- `tools/launcher.test.js`: добавлен регрессионный тест отсутствующего пароля, последующего восстановления и одноразового использования кода.

## Почему
Ранее правильный код мог привести к ответу ok:true с пустым паролем, одновременно погасив код. Телефон затем не мог авторизоваться. Исправление не отключает проверку пароля, лимиты попыток или срок действия кода.

## Простой гайд (Windows + Android)
1. На компьютере установите/обновите AgentLink по [официальной инструкции проекта](docs/INSTALL.ru.md). Пока исправление находится в отдельной ветке, установщик из main его не включает.
2. На компьютере и телефоне включите Tailscale с одной учётной записью. Не используйте публичный туннель для чувствительных задач.
3. На компьютере запустите установщик. В приложении выберите сканирование QR для подключения и подтвердите. Если камера недоступна, используйте код из установщика (однократно, 10 минут).
4. Если не соединяется, запустите установщик с -Doctor (Linux: --doctor). Проверьте serverHealthy, tailscaleState и passwordSaved. Не публикуйте полный вывод, если в нём есть пароль или ссылка сопряжения.
5. При смене пароля используйте -Stop, затем повторный запуск с -Rotate и новое сопряжение телефона. Не удаляйте пароль вручную. Старые подключения потребуют новых данных.
6. Для Codex или Claude Code откройте «Сеансы → Другие агенты». Вход в соответствующего агента выполняется отдельно на компьютере; вход AgentLink не заменяет авторизацию провайдера.

### Команды проверки (PowerShell)
```powershell
$u = 'https://raw.githubusercontent.com/jainikdroid-bit/AgentLink/main/tools/opencode-connect.ps1'
& ([scriptblock]::Create((irm $u))) -Doctor
```
Для Linux/macOS:
```sh
curl -fsSL https://raw.githubusercontent.com/jainikdroid-bit/AgentLink/main/tools/opencode-connect.sh | sh -s -- --doctor
```

## Границы
Это исправление сопряжения AgentLink, а не обход региональных ограничений, OAuth, проверки телефона или входа в OpenAI. Не менялись настройки провайдеров, Tailscale или Android Keystore. Не публикуйте pairingLink, пароль, токены и логи с секретами.

## Исправления по скриншотам и интерфейс
- `tools/launcher.js`: дочерний OpenCode получает OPENCODE_SERVER_USERNAME=opencode, чтобы унаследованное имя пользователя не конфликтовало с Basic Auth установщика.
- `src/stores/connections.ts`, `app/connection/[id].tsx`: проверка существующего подключения с пустым полем пароля использует сохранённый пароль из SecureStore, если URL не изменился. Диагностика использует те же учётные данные. Раньше проверка могла дать ложный 401. Для проверки нового URL прежний пароль не отправляется. Подсказка имени пользователя исправлена на opencode, кнопки проверки и сохранения взаимно блокируются.
- `app/_layout.tsx`: заголовки экранов увеличены, вместо моноширинного шрифта используется обычный полужирный.
- `app/session/[id].tsx`: длинный путь убран из тесной шапки (каталог по-прежнему передаётся экранам файлов и терминала); кнопки файлов, терминала и статистики получили собственные зоны нажатия. Переключатель модели показывает её название без повторяющегося текста. Поле сообщения выше, кнопка отправки контрастнее, текст ошибки выделяется и доступен для выделения.
- `src/stores/events.ts`: извлекается вложенное сообщение ошибки OpenCode (data.message), затем message или name, вместо безликой ошибки; длина ограничена существующей функцией sanitizeBody.
- `src/lib/useOverallStatus.ts`, `src/components/ConnectionStatus.tsx`: при повторной попытке выполнения сессии статус становится предупреждением с номером попытки, состояние агента — неизвестным, а не подтверждённым.
- **3D-персонаж не менять.** По просьбе владельца восстановлены исходные настройки и глобальное отображение Cheri. Перетаскивание, масштабирование, прозрачность, анимации, жесты, меню и сохранение позиции оставлены как в main. Не изменять FloatingCheri, avatar-mood или нативную обработку касаний при следующих правках интерфейса без явной просьбы.

## Проверка интерфейса перед релизом
1. Сохранённое подключение: проверить с пустым полем пароля; сравнить с проверкой после ввода пароля. Для другого URL проверить, что тест не использует старый пароль.
2. На Android проверить длинный путь Windows, маленький экран, клавиатуру и выбор модели; проверить отправку и остановку сообщения.
3. Вызвать ошибку провайдера и повторную попытку; проверить текст ошибки и статус.
4. Проверить перетаскивание и изменение размера Cheri на всех экранах.
5. Выполнить команды тестирования выше и только после этого собирать релиз. Изменения пока в ветке fix/agentlink-auth-guide; версия приложения не повышалась, main не изменён.
